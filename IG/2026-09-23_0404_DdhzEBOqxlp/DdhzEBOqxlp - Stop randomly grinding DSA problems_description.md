## What it teaches

1. Start by asking Claude to visualize the DSA pattern and its sub-patterns.
2. Ask Claude for a list of problems that practice that pattern.
3. If stuck on a problem, ask for hints that do not reveal the answer, and try to solve it yourself.
4. If still stuck, ask for a step-by-step walkthrough of the full solution.
5. Ask for similar problems and keep practicing until the concept is mastered.
6. Ask Claude for a breakdown of time and space complexity.
