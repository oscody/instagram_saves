# One shared AI memory across Claude, ChatGPT, Grok

A seven-slide carousel pitching one shared memory that Claude, ChatGPT and other AI agents can all read and write, with slides on a "Living Brain" app, Notion, Claude's memory consolidation and open-source memory repos. ## What it teaches

1. Create a shared brain in the Living Brain app by giving it a name and an optional description.
2. In ChatGPT, install the Living Brain plugin, then tell ChatGPT to save its memories there.
3. Ask ChatGPT to show your memories to see everything it has stored about you in one view.
4. Keep the shared memory in one Notion Memories page, where ChatGPT, Claude and other agents write what they learn and read it back.
5. Claude's dreaming mode runs between sessions to sort what it learned, fix its own mistakes and find things faster next time.
6. For a free setup, the post points to eight open GitHub repos covering session memory, notes, code memory and long tasks, which Claude Code can wire together.

### Key steps

1. In ChatGPT or Claude, add a custom connector and paste https://api.livingbrain.com/mcp.
2. Sign in with your Living Brain account in the window that opens.
3. Create a brain with a name and an optional description.
4. Ask the assistant to save memories to your brain, or to search what is already saved.
5. For Claude Code, Codex or Cursor, use the MCP with API key setup instead.
