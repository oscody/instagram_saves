# Seven prompts for a brand game with Claude

A nine-slide carousel that walks through seven prompts for building a small 3D browser game with Claude, from picking an idea to pitching a brand. It also shows a racing game example and ends with a comment-to-receive offer.

Written by claude-haiku-5-5.

## What it teaches

1. Prompt 1, the idea: ask Claude for 5 ideas for a small 3D browser game that someone finishes in about 2 minutes and wants to replay. For each idea, get the goal in one line, the controls (arrow keys on a computer, tap on a phone), why it's fun, and how the brand appears without feeling like an ad. Then pick the strongest one and say why.
2. Prompt 2, first playable: ask Claude to build the chosen idea as one HTML page using Three.js, with a 3D scene, a player controlled by arrow keys and by touch, one goal, a score, and a restart button. Add a low-poly style, soft shadows, a sky gradient, the brand's colors, and the brand's product as the thing the player collects. Draw everything with code, no image files, and make sure it runs in the chat and smoothly on a phone.
3. Prompt 3, make it feel good without changing the rules: add a camera that follows the player with a small delay, speed that builds up instead of jumping, a small screen shake on hits, sparks or confetti on scoring, and collisions that forgive near misses. Ask for one line per change explaining what was changed.
4. Prompt 4, make the world worth a screenshot: choose a setting such as a desert canyon at sunset, a snowy forest, or a neon city at night. Add distance fog, trees and rocks placed at random but never on the path, and light that slowly changes. Keep it phone-smooth with simple shadows and no more than 200 objects on screen.
5. Prompt 5, turn it into a real game: add 3 levels that get harder, a start screen with the game's name in big letters, a timer, a best score that is still there next time the game opens, and an end screen with a Play again button and a share button. The share button copies a line like 'I scored [score] in [game name]' plus the game's link, and if copying is blocked it shows the text so the player can copy it manually.
6. Prompt 6, fix what breaks: describe the problem the way a player would (for example, falls through the floor, camera goes inside walls, lags on a phone, touch doesn't work). Ask Claude to find the cause, fix only that, keep everything else the same, and then give 5 things to test before anyone else plays.
7. Prompt 7, pitch it to a brand: publish the game from the chat to get a link. Write a friendly message under 80 words to the brand with the demo link, offering a mini-game for their website and Instagram, a discount code as the prize for a top score, delivery in one week, for $800. Prepare a reply for when they ask why people would play it.
