# Export AI data and skillify repeated tasks

A reel showing a workflow for finding the questions and tasks you repeat most with AI, then turning them into Claude Skills. On-screen prompt cards show the steps for building the skills.

Written by claude-haiku-5-5.

## What it teaches

1. Export your AI chat data by following the platform's export instructions.
2. Give the exported data to your AI agent with the provided prompt so it creates a file on your computer that includes a REPEATS column from the audit.
3. Give that file and a second prompt to your AI so it finds the questions and tasks you repeat most.
4. Paste the REPEATS list into Claude Code and create one Claude Skill per repeated task, each in its own folder in ~/.claude/skills with a SKILL.md file.
5. Write each skill with when to use it, the inputs it needs from you, the exact steps, and the output format you want back.
6. Base the steps and format on how you actually asked the questions in my_questions.txt, so the skill works the way you already work.
7. List every skill you made and the one line you type to run it.
8. Learn the tasks you genuinely need to do yourself rather than automating them, such as using a NotebookLM audio overview.
