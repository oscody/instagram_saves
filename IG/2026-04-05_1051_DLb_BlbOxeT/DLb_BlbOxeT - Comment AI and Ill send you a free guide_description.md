# Building an n8n agent from a YouTube video

A creator shows a chain of tools that turns a YouTube video of an n8n agent into an importable n8n workflow. The steps run through Google AI Studio and a Claude-based agent builder, ending with pasting JSON into n8n.

Written by claude-haiku-5-5.

## What it teaches

1. Copy the YouTube video link of the n8n agent you want to recreate.
2. Paste the link into Google AI Studio together with the workflow-analysis prompt and run it.
3. Copy the prompt that AI Studio generates from the video.
4. Paste that generated prompt into your n8n agent builder, set the model to Claude Opus 4, and run it.
5. Copy the workflow JSON that Claude produces.
6. Paste the JSON into n8n with Ctrl-V to load the agent.
