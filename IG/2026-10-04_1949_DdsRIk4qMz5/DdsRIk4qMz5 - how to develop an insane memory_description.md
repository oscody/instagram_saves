# How to develop an insane memory

A talking-head reel that describes a memory technique linked to the hippocampus, called a memory palace. The on-screen images include a hippocampus brain diagram, a brain graphic, and a room lined with books.

Written by claude-haiku-5-5.

## What it teaches

1. Choose a location you know very well, such as a childhood home.
2. Turn each new piece of information into a scene or object placed in that location.
3. Make the images strange, with weird textures or objects that would only appear in that space; the stranger the better.
4. Connect new information with long-term memory of the location so the brain can hold on to it.
