# Sumiro: AI-built 3D game workflow in six steps

A carousel about developer Shikhar's Sumiro, a 3D game he says he built in 24 hours with AI tools, shown as screenshots of his step-by-step thread. It also notes that the demo's stiff movements came from a Claude bot playing the game.

Written by claude-haiku-5-5.

## What it teaches

1. Step 1: Generate a reference video with Flux 3 Max (on fal). It serves as the reference for the look, world and character.
2. Step 2: Build the world. Screenshot the video, rebuild the assets in Blender, and place them in Three.js. Use dynamic workflows in Claude Code so agents build and check in parallel.
3. Step 3: Make the character. Screenshot the character, create 4 side views with GPT Image, turn them into a 3D model with Tripo, then have Opus add cloth physics and animations.
4. Step 4: Test the gameplay. Play the prototype and check that it works before building more.
5. Step 5: Let the agent build the complete world. Use GPT Image with the existing art style to create concept art for each level, up to 8 images per level.
6. Step 6: Build all the scenes, then iterate. Play the game, report bugs, let the agents fix them and improve the objects, and repeat. Each concept becomes a 3D level you can play.
