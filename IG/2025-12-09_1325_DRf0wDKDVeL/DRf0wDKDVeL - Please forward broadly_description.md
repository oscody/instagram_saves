## Research

* Verdict: Valid. Home Depot's Path to Pro is real, and its Skills Program is free for adults 18 and older. The flyer's "classes offered weekly" claim isn't confirmed, because the official sources describe the training as on-demand and self-paced. The exact /Training URL returned a 404.
* Checked: 2026-10-23 by claude-sonnet-5-5

### Resources

* [Path to Pro (Home Depot) - FAQ (pathtopro.com)](https://www.pathtopro.com/faq/): page, found by search, verified, medium confidence. The official Path to Pro site opened, but only the title loaded. Details on cost and eligibility come from search-result summaries.
* [Home Depot: Empowering trades, expanding Path to Pro (corporate.homedepot.com)](https://corporate.homedepot.com/news/trades-training-and-path-pro/empowering-trades-home-depot-expands-path-pro-initiative): page, found by search, verified, high confidence. Home Depot's corporate page describes the free Skills Program covering electrical, plumbing, HVAC, drywall and painting, plus the Network for jobseekers.

### Key steps

1. Go to PathtoPro.com and open the Skills Program (the flyer's /Training path returned a 404).
2. Register for the free, self-paced Skills Program. It is open to adults 18 and older, in English or Spanish.
3. Start with Skills Basics, which takes about an hour. Then take Trades Essentials courses in electrical, plumbing, HVAC, drywall or painting.
4. Optionally create a profile in the Path to Pro Network (pathtopro.com/find-jobs). Add your resume and photos of your work so hiring pros can find you.
