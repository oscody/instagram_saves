# Why CLI agents beat bespoke AI agents

A talking-head reel with a hand-drawn diagram that defines an AI agent as an LLM using tools, data and web search. It argues that CLI agents such as Codex and Claude Code, which mainly read files and execute code, can replace most custom-built agents.

Written by claude-haiku-5-5.

## What it teaches

1. An agent is an LLM connected to tools, data and web search.
2. CLI agents such as Codex and Claude Code are mainly good at reading files and executing code.
3. Build a couple of folders instead of custom agent harnesses, since the information being read matters more than the reading setup.
4. Use heavier frameworks like LangChain only in specific situations; most business needs are met by something that already works.
