# Four types of ambition for AI prompts

A reel summarizing a post by a Claude lead engineer about asking AI for more ambitious work. It names four types of ambition (speed, altitude, depth, range) and includes a prompt to append to any existing prompt.

Written by claude-haiku-5-5.

## What it teaches

1. Think of ambition in four types: speed, altitude, depth, and range. Speed (the same work in less time) is well established, so skip it.
2. Altitude: move up in abstraction and consider the outcome rather than the individual task.
3. Depth: consider the task the way a field-leading expert would, going one level deeper to the underlying data, tools, and problems.
4. Range: draw on multiple fields, using knowledge, tools, and techniques you normally wouldn't.
5. Use an outside judge: don't ask the model to judge its own result; insist on outside validation, ideally a tool the model can run to get feedback immediately.
6. Append this to your prompt: say what a top professional in this field would do that you're not asking for; name the rawest material they would start from instead of what has already been digested; name the specific methods and tools they would use; say what, other than you or me, would show the result is right.
7. Then rewrite your prompt to ask for exactly those things.

### Key steps

1. Append the prompt to any prompt you already use: "I want a deeper version of this task, not a bigger one."
2. "Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for;"
3. "(2) name the rawest material they would start from instead of what has already been digested for me;"
4. "(3) name the specific methods and tools they would use;"
5. "(4) say what, other than you or me, would show the result is right."
6. "Then rewrite my prompt to ask for exactly that."
7. Run the rewritten prompt. Give the model code execution and an outside check, such as tests or a validator, so it doesn't grade itself.
8. For altitude, ask for the outcome behind the task. For range, restate the task as verbs and ask how experts from several other fields would approach it.
