### Key steps

1. Clone github.com/mintdotgg/mint-playground and run `pnpm install` in the repo root.
2. Pick a demo in the experiences/ folder, e.g. vanguard-protocol, mint-hoops or mossbound.
3. Run it with `pnpm --dir experiences/<name> dev`.
4. Run `pnpm build` to build all experiences.
5. Mint-generated assets load from the Mint CDN and are not in the repo. Try the live versions at play.mint.gg.
