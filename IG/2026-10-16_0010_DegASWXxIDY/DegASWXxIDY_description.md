# Route Claude tasks to Haiku to save limits

The post says Opus handles every small task, such as renaming a file, which uses up Claude usage limits quickly. It describes a sorter that sends easy jobs to the cheaper Haiku 5.5 and keeps only real thinking on Opus.

Written by claude-haiku-5-5.

## What it teaches

1. Sort every Claude task first, before it reaches a model.
2. Send easy tasks such as searching files, reading logs and renaming files to Haiku 5.5.
3. Send only the real thinking work to Opus.
4. Haiku 5.5 is listed at $0.10 per million input tokens, about 90% less per token than Haiku 4.5 at $1.
