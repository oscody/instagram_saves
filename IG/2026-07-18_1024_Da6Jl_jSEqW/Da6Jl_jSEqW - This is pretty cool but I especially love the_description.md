# Free tool that maps a codebase visually

A reel showing an interactive map of a codebase, made with a prompt that a developer credits to a user on X. The speaker says he plans to run it on all his projects to check that the code matches his mental model of the product.

Written by claude-haiku-5-5.

## What it teaches

1. Go to foglamp.dev/scan
2. Click copy prompt
3. Paste the prompt into Claude Code or Codex
4. Run it on your project to get an interactive map of how the codebase fits together
