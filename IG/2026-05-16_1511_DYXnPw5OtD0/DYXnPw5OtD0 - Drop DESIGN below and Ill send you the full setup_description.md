# Turning Claude Design mockups into apps with Codex

A screen-recorded walkthrough shows a LifeOS dashboard being designed in Claude Design, then exported as a standalone HTML file. The clip ends with the file being handed off to Codex.

Written by claude-haiku-5-5.

## What it teaches

1. In Claude Design, create a new high-fidelity project and give it a name.
2. Describe what you want by voice dictation, without needing technical terms, and answer the clarifying questions it asks.
3. Make any further edits you want, then click Share and choose Export as standalone HTML.
4. In Codex, create a new project and start a new chat.
5. Add the downloaded HTML file to the chat, paste the original prompt you wrote in Claude Design, and ask Codex to bring the design to life as a fully built app.
