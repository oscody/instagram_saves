# Two ways to remember what you read

Day 2 of a "learning how to learn in 30 days" series, with Matt describing two ways to remember what you read: a memory-based method and an understanding-based one. Slides list the memory method's three steps over clips of him talking.

Written by claude-haiku-5-5.

## What it teaches

1. Memory way, step 1: set up a memory palace system, where you store information in a mental location.
2. Memory way, step 2: set up a person-action-object (PAO) system, which is how you store information quickly.
3. Memory way, step 3: practice for about one month.
4. Understanding way: treat understanding as a skill you can improve, the same way you improve memorizing with memory palaces and PAO.
