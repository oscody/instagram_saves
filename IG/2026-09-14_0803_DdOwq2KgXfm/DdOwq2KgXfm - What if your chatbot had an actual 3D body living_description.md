# Browser-based 3D AI avatars from text prompts

The reel introduces three.ws, an open-source tool that generates 3D characters from text prompts and runs them in the browser, shown through screens of its GitHub README, a demo avatar and an agent registration confirmation.

Written by claude-haiku-5-5.

## What it teaches

1. Type a text description of the character you want (the README example is "a brass steampunk owl, full body").
2. The system generates a 3D model from the prompt, which can be downloaded as a GLB file.
3. Add an AI (LLM) brain so the avatar can think and remember.
4. Register the agent on-chain and embed the avatar anywhere; it runs natively in the browser with no plugins, downloads or installs.
