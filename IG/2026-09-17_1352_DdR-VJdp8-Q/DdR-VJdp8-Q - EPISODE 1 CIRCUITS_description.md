# Episode 1: Circuits – Becoming a Robotics Engineer

Episode 1 of a series following a marketing graduate's attempt to become a self-taught robotics engineer, introducing the electronics topics to learn before building robots. It also names a free course, a book, an app, and a circuit simulator, and previews soldering as the next episode.

Written by claude-haiku-5-5.

## What it teaches

1. Learn voltage first.
2. Learn Ohm's law.
3. Learn series and parallel circuits.
4. Learn the basic electronic components.
5. Learn how to read a schematic.
6. Learn how to wire a simple circuit.
7. Practice with an Arduino kit or an online circuit simulator.

## Caption

EPISODE 1: CIRCUITS ⚡️

Can you become a robotics engineer with absolutely no technical background?

If you’re interested, you can learn alongside me.

Before building robots, you need to understand how electricity moves through a circuit. Start by learning:

- Voltage
- Ohm’s law
- Series and parallel circuits
- Basic electronic components
- How to read a schematic
- How to wire a simple circuit

Free course: Engineering4Free.com

BOOK: Complete Electronics Self-Teaching Guide with Projects by Earl Boysen and Harry Kybett. 

App: Ohmie

You can start with an Arduino kit or practice using an online circuit simulator. I chose a random Amazon project: the DIY Soldering Practice Kit with a DS18B20 Temperature Sensor Module.

Next episode: learning how to solder. Follow along, and maybe we’ll build a real robot together.
