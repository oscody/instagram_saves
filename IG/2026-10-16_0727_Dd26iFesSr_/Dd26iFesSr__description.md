## What it teaches

1. Organize business files into folders instead of one giant data dump, so the AI knows where to look.
2. Keep one short memory file that the AI reads first every time, so it doesn't ask the same questions twice.
3. Write down the automations that save time or make money.
4. Set up workflows that run those automations on a schedule so work happens without you.
