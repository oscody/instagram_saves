# Google's Gemini 3 Pro and Antigravity platform overview

A creator reviews Google's Gemini 3 Pro release and Antigravity, an agentic development platform, and describes it as a partner rather than a chat-based vibe coding tool. Screen recordings show a flight tracker app built in localhost and a Three.js rocket animation prompt with the agent's plan.

Written by claude-haiku-5-5.

## Caption

Google launched Gemini 3 Pro today as well as ANTIGRAVITY – their new agentic development platform.

It helps developers build faster by collaborating with AI agents that can autonomously operate across the editor, terminal, and browser.

Essentially, it’s a full VS Code fork, which will disappoint some – but with Gemini 3 Pro built directly into it.

Now, it will take a few days for the developer community to determine whether it outperforms Cursor and some of the other IDEs.

But the advantages that Antigravity has, is that it’s coupled with Gemini 3 Pro (SOTA) Gemini 2.5 Computer Use and Nano Banana for rich media generation.

Let’s talk about Gemini 3 Pro.

There’s really no other way to say it. The benchmarks are incredible. The jump was dramatic – much more than most people expected.

Not that benchmarks really matter all that much IMO - but it should make Google investors happy as it’s going to be difficult for other frontier labs to match them in the next several months.
