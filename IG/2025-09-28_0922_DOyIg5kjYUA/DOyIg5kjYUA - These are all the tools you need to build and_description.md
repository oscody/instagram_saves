# Stack for building and launching a web app

A reel listing the tools used to build and launch a web app in about a week, covering the coding editor and AI assistants, a domain, hosting, and analytics with session replays. It ends by asking viewers which app to build next.

Written by claude-haiku-5-5.

## What it teaches

1. Code in Windsurf as the editor.
2. Start with Claude Code inside Windsurf; when it stopped working well, switch to Codex.
3. Drop Codex because it opened a pull request for every edit, which caused merge conflicts; use GPT-5 inside Windsurf instead.
4. Generate animations for the site with a sprite sheet generator (the author's own tool).
5. Get a domain from GoDaddy, or a free domain from GitHub Pages.
6. Host the site on Vercel, which has a free tier (the author pays for Pro to get more observability across several apps).
7. Track visitors with Data Fast for user counts and a globe showing where users are and what they do.
8. Watch session replays with PostHog to see how people move through the app, what frustrates them, and what works, instead of relying only on errors and logs.
