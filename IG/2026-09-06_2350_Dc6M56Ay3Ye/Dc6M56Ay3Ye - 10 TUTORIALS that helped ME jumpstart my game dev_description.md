# 10 game dev tutorials for beginners

A reel in which the creator lists 10 YouTube tutorials that they say helped them start game development, mostly about Godot, with on-screen clips of each video. The caption adds hashtags for Godot, Blender and indie games.

Written by claude-haiku-5-5.

## What it teaches

1. Start with the Ultimate Introduction to Godot by ClearCode (about 8 hours).
2. Next, watch How to Learn Godot Fast by Code With Ro.
3. Then watch How to Program in Godot by Brackies.
4. Learn file naming: snake_case and PascalCase matter.
5. Watch Brackies' How to Make a Video Game.
6. Learn state machines with the Chap.C Games video The First Skill GODOT Beginners Should Learn - State Machine Game Showcase.
7. Watch the Shaggy Dev video on starter state machines in Godot 4.
8. Watch the advanced state machines video that follows.
9. Learn Control Nodes with Godot Control Node (UI) Masterclass by Karto.
10. Finish with Game Maker's Toolkit, which covers the basics of AI.
