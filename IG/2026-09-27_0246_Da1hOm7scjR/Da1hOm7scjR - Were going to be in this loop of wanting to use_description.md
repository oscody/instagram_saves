# Cutting AI costs by delegating work to cheaper models

A man in a green hoodie explains a workflow for using an expensive top-tier model without burning through usage limits, with a cheaper model doing the bulk of the work. On-screen text reads "Ur using Claude at 5%," and the caption says the cost of the newest model is a constant pull, so it's worth getting good at this.

Written by claude-haiku-5-5.

## What it teaches

1. Write a brain-dump list of everything that needs to get done.
2. Have the expensive model act as orchestrator and hand the list to it.
3. Have the orchestrator create a sub-agent using a cheaper Opus profile to execute all the tasks.
4. The Opus worker agents run the tasks, possibly with several helper agents working in parallel.
5. When the workers finish, they send their results back to the orchestrator for review.
6. The orchestrator reviews the work and lists specific fixes; the workers apply them and resubmit.
7. Repeat the review and fix loop until the orchestrator judges the result good enough.
8. The orchestrator reports the finished result back to you.
