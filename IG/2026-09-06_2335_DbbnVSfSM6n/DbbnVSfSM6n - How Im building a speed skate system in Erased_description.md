# Building a speed skate system in Erased

A game developer shows the speed skating system in their game Erased, comparing it to Alita: Battle Angel, with clips of the character wrapping around slopes and a motion capture app.

Written by claude-haiku-5-5.

## What it teaches

1. Write a new movement script that sticks the character to any terrain instead of assuming flat ground.
2. Angle and turn the character's body to match the slope it is moving down or across.
3. Record a reference video of the desired motion and extract motion capture data from it with a motion capture app.
4. Retarget the captured motion onto your own 3D model.
5. Adjust the animation in Blender, then import it back into Unity.
6. Apply the same terrain-angling approach to the walking mechanic.
