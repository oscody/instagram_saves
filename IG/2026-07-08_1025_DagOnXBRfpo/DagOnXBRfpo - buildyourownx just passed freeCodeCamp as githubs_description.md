# Build-your-own-x repo as an interview project

The post says the build-your-own-x GitHub repo has become the most-starred repo, and that the project you build from it matters in interviews. The speaker adds that most engineers she interviewed have no real side project.

Written by claude-haiku-5-5.

## What it teaches

1. Use build-your-own-x to pick a technology to rebuild from scratch, such as a database, git, or an operating system.
2. Prefer a systems project like a database or git over a basic game or AI model, which the post says reads as following a tutorial.
3. Add your own extras and bells and whistles beyond the basic version so the project stands out.
4. Put the finished project on your resume, since the speaker says few engineers have a real side project.
