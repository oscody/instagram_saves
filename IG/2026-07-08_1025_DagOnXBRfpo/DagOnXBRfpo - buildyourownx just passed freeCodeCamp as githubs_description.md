# Build-your-own-x repo as an interview project

The post says the build-your-own-x GitHub repo has become the most-starred repo, and that the project you build from it matters in interviews. The speaker adds that most engineers she interviewed have no real side project.

Written by claude-haiku-5-5.

## What it teaches

1. Use build-your-own-x to pick a technology to rebuild from scratch, such as a database, git, or an operating system.
2. Prefer a systems project like a database or git over a basic game or AI model, which the post says reads as following a tutorial.
3. Add your own extras and bells and whistles beyond the basic version so the project stands out.
4. Put the finished project on your resume, since the speaker says few engineers have a real side project.

## Research

* Verdict: Partly valid. The repo is real and public, and its star count (about 555k) is above freeCodeCamp's (about 458k). I did not check whether it is #1 on all of GitHub. The advice about interviews is the speaker's opinion.
* Checked: 2026-10-22 by claude-sonnet-5-5

The description is 'Master programming by recreating your favorite technologies from scratch', and the list includes Database, Git and Operating System. It shows about 555k stars.
* [freeCodeCamp/freeCodeCamp (github.com)](https://github.com/freeCodeCamp/freeCodeCamp): repo, found by search, verified, high confidence. Opened it. It shows about 458k stars, below build-your-own-x, so that part of the claim holds.

### Key steps

1. Open the build-your-own-x README and browse the categories (Database, Git, Operating System, Shell, Regex Engine, Web Server and others).
2. Pick a systems-level project, not a basic game or AI model.
3. Follow a linked tutorial to build it, then add your own features beyond the tutorial.
4. Write it up on your resume and README, and explain your design choices in interviews.
