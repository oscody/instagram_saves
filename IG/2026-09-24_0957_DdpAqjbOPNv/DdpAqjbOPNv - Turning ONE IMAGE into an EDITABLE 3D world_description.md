# Turning One Image Into an Editable 3D World

A creator demonstrates Hyper3D's WorldGen tool, which turns a single castle image into an explorable 3D scene where each marked object becomes a separate, editable asset. The video shows the workflow in the tool and a result opened in Blender.

Written by claude-haiku-5-5.

## What it teaches

1. Switch to WorldGen in Hyper3D and upload a single image of the scene.
2. Mark the objects you want as separate 3D assets using New Object and Add, or use Auto Extract to let AI segment them.
3. Click generate on each marked object so it is built as its own 3D asset.
4. Once all objects are generated, choose FastGen or Max Gen to generate the full scene (the creator uses Max Gen for the best results).
5. Orbit the finished scene and select objects to move or scale them.
6. Download the world and open it in Blender to edit the objects.
