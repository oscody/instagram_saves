# Using AI-built simulations to learn complex topics

A podcast clip where the host and guest discuss turning hard topics into interactive, SimCity-style simulations. On screen are a blog article about the workflow and the TokenTown site, which lays out a language model as a city.

Written by claude-haiku-5-5.

## What it teaches

1. In plan mode (using Claude Code or OpenCode), ask a model to build the foundational knowledge for the topic you want to learn.
2. Ask the model to review the accuracy of the knowledge base it built in the previous step.
3. Ask the model to build a simulation of that topic as a low-poly, Rollercoaster-style game (the on-screen line is cut off here).

### Key steps

1. In plan mode (Claude Code or OpenCode), ask the model to build a foundational knowledge base on your topic.
2. Ask the model to review that knowledge base for accuracy.
3. Ask it to build a low-poly, theme-park or city-builder style simulation of the topic (the on-screen line is cut off).
4. To try the example, open TokenTown, type a prompt and press Run. Then press Space to pause, S to step, R to replay, and adjust Temperature and Top-p.
