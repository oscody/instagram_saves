# AI agent team with OpenClaw and Hermes

A creator walks through a setup of AI agents on a laptop, with OpenClaw as a supervisor that plans and delegates and Hermes as an executor that learns from each completed task. On-screen mockups show a 9am inbox and calendar briefing sent to Telegram, a live lead-generation run, and a trend-scanning content workflow.

Written by claude-haiku-5-5.

## What it teaches

1. Install OpenClaw and choose GPT 5.5 as its model.
2. Connect OpenClaw to Telegram.
3. In CloudHub, choose the skills the agents will use, such as email monitoring, content scheduling, and content research.
4. Install the Hermes agent from Nous Research and set Claude Sonnet 4.6 as its model.
5. Structure the setup as a supervisor-builder workflow: OpenClaw plans and delegates, while Hermes does the work.
6. Have Hermes save each completed task as a reusable skill so the workflow improves over repeated runs.
7. Schedule a daily 9am task in Hermes that checks the inbox, summarizes emails needing a reply, pulls the day's calendar events, and sends the briefing to Telegram.
8. Add more agents, such as a content monitoring agent that scans trending niche topics and a client outreach agent that drafts follow-ups, and run them in parallel.
