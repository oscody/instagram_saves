## What it teaches

1. Open Claude Code in the terminal and run the projects there so the /goal command is available.
2. Use /goal so the agent keeps looping until the task is done.
3. Write each prompt with a CONSTRAINTS line that sets limits, such as using real data and excluding certain YouTube channel types.
4. Add a VERIFICATION line that tells the agent to check the result in a browser, confirm the data loads, confirm the main interactions work, and confirm results match the scraped data.
5. For planning tasks, state who is coming, your constraints, and their preferences, then let Claude produce the itinerary.
6. Work through the six projects: a 3D spider simulation, a browser dragon-flying game, a YouTube interest visualizer, a week of brand-voice content, an overnight A/B test optimizer, and a trip itinerary.
