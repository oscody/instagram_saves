# FCRA Credit Removal Statute Citations by Debt Type

The opening slide claims the FCRA lets you permanently remove anything hurting your credit. The following slides list US Code section numbers under headings for debt types such as late payments, medical bills, collections, evictions and charge offs.

## What it teaches

1. Late payment: cite 15 US Code 1681a (2Xi) and 15 US Code 1666b
2. Medical bills: cite 15 US Code 1681b (aX2) and 15 US Code 1692g
3. Collections: cite 15 US Code 1692c, 15 US Code 1692g and 15 US Code 1681e(b)
4. Repossessions: cite 15 US Code 1681b (aX2)
5. Child support: cite 15 US Code 1681b and 15 US Code 1681s-1
6. Evictions: cite 15 US Code 1637 (2) 9A, 15 US Code 1681, 15 US Code 1681s-2 (aX3) and 15 US Code 1681e (b)
7. Charge offs: cite 15 US Code 1635 and 15 US Code 1692g
