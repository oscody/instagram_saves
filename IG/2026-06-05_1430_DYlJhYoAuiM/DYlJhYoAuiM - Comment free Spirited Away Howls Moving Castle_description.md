# Free open-source Ghibli animation software OpenToonz

The reel presents OpenToonz, a free, open-source 2D animation program that the speaker says is based on Studio Ghibli's customized Toonz version, and shows its GitHub README on screen. It also says the software is available for Windows, Mac, and Linux.
