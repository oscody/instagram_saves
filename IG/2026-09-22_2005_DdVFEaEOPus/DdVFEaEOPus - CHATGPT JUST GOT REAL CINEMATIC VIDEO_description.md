# Setting up Higgsfield plugin in ChatGPT for video

Shows the Higgsfield plugin being added and authorized in ChatGPT, then a 9:16 rain-on-windshield clip generated with Seedance 2.5 in the chat and revised with "warmer light" in the same thread.

Written by claude-haiku-5-5.

## What it teaches

1. In ChatGPT, go to Settings, open Plugins, and add Higgsfield.
2. When the OAuth prompt appears, allow access.
3. Type your cinematic prompt in ChatGPT with the Higgsfield connector selected, and the video generates in the thread.
4. To change the result, type the adjustment you want (for example, "warmer light") in the same thread and it re-renders as a new version.

### Key steps

1. Open the Plugins directory in ChatGPT and find Higgsfield. You can also use the add button at higgsfield.ai/mcp.
2. Click Add and sign in with your Higgsfield account. Allow access when the OAuth prompt appears.
3. Start a new chat, select Higgsfield or mention it, and ask for an image or video. You can name a model such as Seedance 2.5, Kling 3, Nano Banana Pro, GPT Image 2 or Soul 2.0. If you don't, ChatGPT picks one.
4. Ask for changes in the same thread, for example "warmer light", and it re-renders.
5. Every generation costs Higgsfield credits. For example, a 15-second Seedance 2.5 video at 1080p costs 270 credits. Unlimited model access works only in the Higgsfield web app, not through ChatGPT.
6. Plugin availability can depend on your plan, region and workspace settings.
