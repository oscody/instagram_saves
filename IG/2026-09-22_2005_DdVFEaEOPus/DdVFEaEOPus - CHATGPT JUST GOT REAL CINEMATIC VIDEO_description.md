# Setting up Higgsfield plugin in ChatGPT for video

Shows the Higgsfield plugin being added and authorized in ChatGPT, then a 9:16 rain-on-windshield clip generated with Seedance 2.5 in the chat and revised with "warmer light" in the same thread.

Written by claude-haiku-5-5.

## What it teaches

1. In ChatGPT, go to Settings, open Plugins, and add Higgsfield.
2. When the OAuth prompt appears, allow access.
3. Type your cinematic prompt in ChatGPT with the Higgsfield connector selected, and the video generates in the thread.
4. To change the result, type the adjustment you want (for example, "warmer light") in the same thread and it re-renders as a new version.
