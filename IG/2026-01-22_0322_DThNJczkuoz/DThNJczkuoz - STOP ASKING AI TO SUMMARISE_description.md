# Stop asking AI to summarise: eight prompts

A whiteboard infographic arguing that summaries reduce information while strategic prompts improve judgement, with eight numbered prompt patterns for using AI as a thinking partner. Credits Charlie Hills for the visuals.

Written by claude-haiku-5-5.

## What it teaches

1. Extract strategic insights: prompt the AI to act as a strategy consultant, identify the 5 most valuable insights, and explain which decisions each one informs.
2. Turn information into action: ask for a 5-step plan with clear owners, quick wins, and measurable results.
3. Surface hidden assumptions: ask it to reveal unstated assumptions or blind spots behind an argument and what changes if they're wrong.
4. Compare opposing views: map an idea against two competing perspectives, showing where they align, where they differ, and which context fits each.
5. Distil for a specific role: filter the core idea through a role's lens, e.g. marketer (reach/conversion), founder (cash flow/growth), engineer (feasibility/scale).
6. Build a reusable model: extract the repeatable framework in the text and label each stage's input, process, output, and feedback/refine loop.
7. Extract contrarian takeaways: find insights that would challenge smart peers while staying credible, and write each as a sharp one-liner.
8. Identify leverage points: highlight the 3 points where small actions could create outsized results and explain why each one matters.
