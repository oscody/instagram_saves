# The only prompt to bypass AI detection

A slide titled "The only prompt you need to bypass AI-detection in your writing" lays out a three-step ChatGPT workflow: list writing patterns, turn them into a custom instruction, and save it in settings. The text is shown in the image, with no caption beyond the title.

Written by claude-haiku-5-5.

## What it teaches

1. Open ChatGPT in a new chat and paste the first prompt, which asks it to search the web and list every pattern that reveals AI-generated writing, with the pattern name, what it looks like in a sentence, and one example each.
2. In the same chat, ask ChatGPT to turn every listed pattern into a strict writing rule and combine them into one custom instruction block (varied sentence length, contractions, short fragments, hedging words, a personal aside, and a ban on words like delve, moreover, furthermore, and underscore, with the output formatted for pasting into settings).
3. Copy the rule block from ChatGPT.
4. Tap your profile photo in the top right, then Settings, then Personalization, then Custom Instructions.
5. Paste the block into the custom instructions field and tap Save, so new chats follow the rules without pasting them again.
