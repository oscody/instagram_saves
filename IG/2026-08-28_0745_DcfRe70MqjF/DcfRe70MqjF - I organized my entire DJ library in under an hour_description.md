# Organizing a Rekordbox DJ library with Claude

A DJ walks through how she used Claude to sort her Rekordbox library into genre playlists, from exporting the XML to re-importing it. Her caption and on-screen text summarize the same process.

Written by claude-haiku-5-5.

## What it teaches

1. Back up your library before starting.
2. Export your Rekordbox library as XML.
3. Give the XML to Claude so it can map the whole library.
4. Have Claude analyze your existing playlists to learn your BPM ranges, artists, and genre patterns.
5. Tell Claude how you organize: which folders to skip, how to split genres, naming conventions, what to do with tracks in multiple places, and other edge cases.
6. Let Claude classify your unorganized tracks into the right playlists, including new playlists it suggests.
7. Review every assignment in a searchable browser before importing.
8. Go back and forth with Claude to correct mistakes, since you still need to review and fix the results.
9. Have Claude audit the library for duplicates and misclassifications.
10. Import the organized XML back into Rekordbox.
