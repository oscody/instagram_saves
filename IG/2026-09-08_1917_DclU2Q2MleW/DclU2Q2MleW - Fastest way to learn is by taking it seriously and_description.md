# Five Blender tutorials that build real 3D skill

A man in a black shirt talks to camera and recommends five Blender tutorials, shown as video thumbnails on screen. He says these build 3D skill better than watching more tutorials.

Written by claude-haiku-5-5.

## What it teaches

1. Take learning seriously and don't rely on others to challenge you.
2. Cinematic lighting: the one-point-light studio tutorial by Polyboard teaches the cinematic feel with a single point light.
3. Materials: the Kaizen tutorial goes deep into masking, which the speaker calls the biggest difference between pro materials.
4. Compositing: the Extra 3D beginner tutorial explains how the compositing process works and why it matters.
5. Lazy Tutorials by Ian Hubert: after finishing one, try to make something else with what you learned to learn much more.
6. Geometry nodes: the CrossMind Studio approach explains how to think about geometry nodes before starting, rather than only applying an effect.
