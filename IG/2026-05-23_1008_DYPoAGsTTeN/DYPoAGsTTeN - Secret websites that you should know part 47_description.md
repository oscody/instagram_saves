# Awesome Claude resource directory for Claude Code

The video shows the Awesome Claude directory site, including its Claude Code cheat sheet of slash commands and a grid of feature cards such as a status line, voice input, and conversation search.

Written by claude-haiku-5-5.

## What it teaches

1. /clear clears the conversation history
2. /cost shows token usage statistics
3. Ctrl+B moves long-running bash commands to the background, and Claude can check on them later
4. All conversations are stored in ~/.claude/projects/, where you can search with grep or ask Claude directly

### Resources

* [Awesome Claude (directory) (awesomeclaude.ai)](https://awesomeclaude.ai): page, in the post, verified, high confidence. The page is a curated, MIT-licensed directory of Claude and Claude Code resources, as in the post.
* [Claude Code Cheatsheet (awesomeclaude.ai)](https://awesomeclaude.ai/code-cheatsheet): page, found by search, verified, medium confidence. I guessed this URL from the directory's 'Code Cheatsheet' link and it opened. It lists /clear, /cost and Ctrl+B.

### Not found

The cheatsheet doesn't confirm that conversations are stored in ~/.claude/projects/. It only mentions auto-memory notes under that path. Separately, the main directory page I opened didn't show the status line, voice input or conversation search cards from the video.
