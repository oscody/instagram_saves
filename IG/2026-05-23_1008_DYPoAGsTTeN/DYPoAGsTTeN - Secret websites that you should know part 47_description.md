## What it teaches

1. /clear clears the conversation history
2. /cost shows token usage statistics
3. Ctrl+B moves long-running bash commands to the background, and Claude can check on them later
4. All conversations are stored in ~/.claude/projects/, where you can search with grep or ask Claude directly
