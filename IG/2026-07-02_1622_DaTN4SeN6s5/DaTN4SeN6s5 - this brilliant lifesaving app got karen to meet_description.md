# Karen's Swift Challenge app to escape floods

Karen Havok, from Ghana, talks about her offline flood-escape app that won Apple's Swift Student Challenge and how she built it. The caption links the app to real flooding in Ghana and encourages viewers to build something that solves a problem near them.

Written by claude-haiku-5-5.

## What it teaches

1. Pick a real problem around you to solve, such as flooding in your area.
2. Use the skills you already have to build a solution.
3. Research the problem and understand how the system will work before building.
4. You don't need to know how to write code first; define what you want, then use an AI agent to help build it.
5. Take the first step and start building.
