### Key steps

1. Use Linux or macOS with Python 3.10+. Windows isn't supported.
2. git clone https://github.com/Z4nzu/hackingtool.git && cd hackingtool
3. pipx install . (or: uv tool install .)
4. Run: hackingtool
5. Or use Docker: docker run -it --rm hardikzinzu/hackingtool:latest
6. Some individual tools need extra runtimes such as Go, Ruby or tmux.
7. Use it only on systems you own or are authorized to test.
