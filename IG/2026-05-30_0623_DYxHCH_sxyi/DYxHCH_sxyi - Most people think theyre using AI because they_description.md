# AI employee stack: Hermes, Claude Code, Obsidian

A reel presenting a connected AI setup, with Hermes as the central agent, Claude Code as the bridge, and Obsidian as the notes store, shown with a person typing at a laptop in a restaurant. It also claims the stack can handle scheduling, email drafts and lead research.

Written by claude-haiku-5-5.

## What it teaches

1. Use Hermes as the central hub and create several AI personas in it, each with its own role and assigned model (for example research, reasoning, execution).
2. Sync Hermes with Claude Code so mobile chats (via Telegram) and desktop development share the same context and memory.
3. Send insights, decisions and notes into Obsidian so they are stored in a second brain, with Hermes connected to it.
4. Connect the stack to Zapier and Apollo for business tasks such as scheduling, drafting emails and researching leads.
