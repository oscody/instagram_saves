### Resources

### Key steps

1. Requires Python 3.11+.
2. Install from PyPI: uv pip install agentscope
3. Or from source: clone the repo, cd agentscope, uv pip install -e .
4. Use the examples/web_ui folder for a web UI, or the terminal console to chat with agents.
5. Add tools through the toolkit (Python functions, MCP servers, skills).
6. For teams, use Agent Team or TeamPipeline.
