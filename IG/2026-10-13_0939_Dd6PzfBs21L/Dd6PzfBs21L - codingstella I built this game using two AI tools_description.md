# Combining Tripo and Astra for a 3D game

The post shows a jelly-jungle platformer built with two AI tools: 3D assets are generated and refined in Tripo, then placed and scripted in Astra. It walks through the split of work between the two tools and says the same approach works for weapons, props, and products.

Written by claude-haiku-5-5.

## What it teaches

1. Generate the 3D asset (the character) in Tripo when you want more control over how it looks.
2. Refine the generated asset in Tripo.
3. Bring the refined asset into Astra.
4. In Astra, build the game scene around the asset: place objects and set up the environment.
5. In Astra, add controls and interactions, and write the code behind them.
6. Use the same process for custom weapons, props, and products, not only characters.
7. Combine tools so that each one handles the part it does best.

## Caption

coding.stella 🎮 I built this game using two AI tools, and here’s why I combined them.

Astra is great at building the scene around your assets - placing objects, setting up the environment, and adding interactions with code.

But when it came to the actual 3D assets, I wanted more control over how they looked.

So I generated the character in Tripo, refined the asset, and brought it into my Astra workflow.

From there, Astra handled:
🗺️ The game scene
🎮 Controls
⚡ Interactions
💻 The code

And this workflow isn’t just useful for characters.

You can use the same process for custom weapons, props, products, and more.

Instead of relying on one tool for everything, combine them and let each tool handle what it does best. 🚀
