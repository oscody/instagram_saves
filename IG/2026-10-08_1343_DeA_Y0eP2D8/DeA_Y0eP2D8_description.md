### Key steps

1. Open tinyworld.build in a browser. No install is needed.
2. Place blocks, terrain, props, homes, paths and crops.
3. Sculpt terrain: R raises and F lowers the hovered cell.
4. Drag to orbit and scroll to zoom. P or I cycles the isometric, soft and perspective views.
5. Save, export or remix worlds. Seeded URLs such as ?demo=vehicles&seed=... reload the same demo.
6. To run it locally, run npm run dev and open localhost:3000/tiny-world-builder, or open index.html directly.
