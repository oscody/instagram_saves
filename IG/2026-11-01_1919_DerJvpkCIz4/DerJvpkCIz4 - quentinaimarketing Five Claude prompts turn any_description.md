# Five Claude prompts for learning any topic

A seven-slide carousel offering five Claude prompt templates for learning a skill or topic, from a free day-by-day plan to expert-level test questions. Each prompt has a bracketed placeholder for the subject.

Written by claude-haiku-5-5.

## What it teaches

1. Copy any of the five prompts into Claude and replace the bracketed placeholder with your topic.
2. Master a skill for free: ask Claude to act as a master of the skill with 20+ years of experience, reverse engineer the process behind that level, then build a day-by-day plan to reach it as fast as possible using only free resources.
3. Turn confusion into clarity: for a concept you don't understand, ask Claude to break it down step by step using metaphors, visual images and real-world examples, then give you a mental shortcut or framework to remember it.
4. Get a PhD-level breakdown: ask Claude to teach the topic as if you were preparing for a PhD, starting from first principles, explaining every major theory, showing how the field evolved, and listing key papers and books to go further, only ones it is sure exist.
5. Fix your mental blocks: for a work blocker you keep struggling with, ask Claude to analyse it like a cognitive scientist, find the root causes and behavioural patterns behind it, then design a habit loop to get rid of it.
6. Understand like a genius: for a topic you want to understand, ask Claude to break it down with advanced analogies, real-world applications, counterexamples and multiple perspectives, then test you with expert-level questions.
