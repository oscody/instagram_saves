# 50 date ideas to text instead of WYD

A man in a bathroom shows an on-screen list of 50 date activities, from rooftop dinner and mini golf to aquarium date, to send instead of "WYD?". The sample opener reads "Hi beautiful, would you like to go ____?"

Written by claude-haiku-5-5.

## What it teaches

1. Don't open with a vague text like "WYD?"
2. Send a specific invite: "Hi beautiful, would you like to go ____?"
3. Fill the blank with one activity from the list of 50 (e.g., rooftop dinner, wine tasting, paddle boarding, pottery class, aquarium date)
