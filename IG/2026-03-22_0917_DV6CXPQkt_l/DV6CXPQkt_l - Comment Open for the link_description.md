### Key steps

1. Check you have Node.js 18+, Git and Claude Code 2.1+.
2. Either run `npx ecc-universal@2.2.3 setup`,
3. or inside Claude Code run `/plugin marketplace add https://github.com/affaan-m/ECC` and then `/plugin install ecc@ecc`.
4. Use only one install method per harness, not both.
5. For continuous learning, use commands such as `/learn-eval` and `/evolve` to turn sessions into instincts and skills.
