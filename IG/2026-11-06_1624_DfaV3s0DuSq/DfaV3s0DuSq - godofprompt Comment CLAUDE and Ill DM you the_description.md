# Blender 3D product videos with Claude

The carousel shows Claude working inside Blender to build a product studio, turn a product photo into a 3D model, and render a looping spin video, with seven copy-paste prompts on the slides. It also covers placing the product in an ad-style scene and writing a brand pitch DM.

Written by claude-haiku-5-5.

## What it teaches

1. Set up: install the Claude desktop app with the Blender connector, and use free Blender 5.1 or newer with the MCP add-on switched on.
2. Studio setup: have Claude list and clear the open scene, set units to centimetres, frame size 1080 by 1350, 30 fps, then build a white curved backdrop, a soft key light from the left, a thin backlight, and a camera at product height.
3. Product model: upload one photo, give the product type and real height in cm, and have Claude build it at real size matching the outline, proportions, lid and label position with no invented details. Render a front and a three-quarter view and check what differs from the photo.
4. Materials: pick a material for the body (glass, matte ceramic, brushed metal or frosted plastic) and for the lid, place the label image on the label area without stretching, round sharp edges slightly, add a soft contact shadow, and add a little roughness. Render one frame and look for what still looks fake.
5. 6-second spin: animate a full turntable turn with a slight camera move in, make the last frame match the first so it loops, then render MP4 at 1080 by 1350, 30 fps with Eevee. Before the full render, check stills of frames 1, 90 and 180.
6. Ad scene: place the product in a real-looking setting such as a marble bathroom shelf, a wooden kitchen counter or a rock in shallow water, built at real scale. Keep the product sharp in the middle with a slightly blurred background, and render an 8-second slow push-in with the light moving across the label, using the same render settings.
7. Pitch: write a short, friendly Instagram DM to a small brand with the video attached, saying you made it from one photo of their product, where they could use it, and your offer.
8. Fix and check: name the exact flaw and frame number, have Claude fix only that and keep everything else the same, then run a checklist before sending any video: real size, shadows, label edges, smooth loop, and file under 100 MB for Instagram.

### Key steps

1. Install Claude Desktop. Go to Customize > Connectors, search for Blender, and select Add.
2. Install Blender (Anthropic says 4.2 or later; the post says 5.1 or later). Drag the install link from the Blender MCP Server page into Blender and allow the 'lab' extension repository.
3. In Blender, go to Edit > Preferences > Add-ons > BlenderMCP and start the MCP server. Do this each session.
4. Prompt 1: have Claude list and clear the scene, then set cm units, 1080x1350, 30 fps, and build a white curved backdrop, a key light, a backlight and a camera.
5. Prompt 2: upload one product photo with its real height and have Claude build the model. Render front and three-quarter views and compare them to the photo.
6. Prompt 3: set the materials and label, round the edges, add a contact shadow, and render a frame to check for anything that looks fake.
7. Prompt 4: make a 6-second looping turntable spin, render MP4 with Eevee at 30 fps, and check frames 1, 90 and 180 first.
8. Prompts 5-7: put the product in an ad scene (8-second push-in), write a DM pitch to the brand, then fix flaws one at a time and run the checklist (file under 100 MB).
