# AI stack for building hackathon projects fast

A creator talks through the AI tool stack he says he used to win a hackathon, running from idea generation through UI, code review and backend. On-screen text shows the prompt to use with v0's generated frontend.

Written by claude-haiku-5-5.

## What it teaches

1. Use ChatGPT to generate a list of about 10 ideas, and think of them as a product rather than as code.
2. Pick the two or three best ideas and keep iterating on them until one stands out.
3. Ask ChatGPT for a detailed description of the chosen idea to use as a prompt for Vercel v0, which generates the UI in one shot.
4. After v0 generates the code, play with it, download it, and open it in Cursor.
5. In Cursor's Ask mode, prompt: "Summarize the structure of this frontend generated by v0" so Cursor understands the code before you build on it.
6. Use Supabase for the backend and authentication.
7. Add a system prompt in Cursor telling it to be as efficient as possible, since its generated code has become verbose.
8. When you hit a syntax or library you don't understand, ask GPT-4o mini high or Perplexity to explain it.
