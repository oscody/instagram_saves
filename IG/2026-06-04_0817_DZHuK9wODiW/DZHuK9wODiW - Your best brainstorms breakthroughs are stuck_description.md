# Export AI chats to markdown with Chrome plugins

A reel showing free Chrome extensions for ChatGPT, Claude and Gemini that export full chat threads as markdown files. It walks through the hover-button export on screen and notes which chats are worth saving.

Written by claude-haiku-5-5.

## What it teaches

1. Install the free Chrome extension for each tool you use (ChatGPT, Claude, Gemini).
2. Open the chat you want and hover over the export button on the right-hand side of it.
3. Select all, then load all messages so the full thread is included.
4. Click Export and choose markdown, which downloads a .md file.
5. Move the downloaded markdown file into your AI Brain folder.
6. Before exporting, decide which threads are valuable (your voice, brand, ICP, offers) and skip the rest, such as random rabbit holes.
