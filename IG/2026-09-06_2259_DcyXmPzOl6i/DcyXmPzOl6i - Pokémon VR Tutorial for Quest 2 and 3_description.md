# Pokémon VR Tutorial for Quest 2 and 3

A screen-recorded walkthrough of installing the Dramatic Shape app on a Meta Quest 2 or 3 with SideQuest and playing Gen 1 Pokémon games and Pokémon Stadium in VR. The app's GitHub page and the Quest 3 APK download are shown on screen, and the poster says the links are in their YouTube video description.

Written by claude-haiku-5-5.

## What it teaches

1. Download the Quest 3 APK of Dramatic Shape from the Releases section of its GitHub page.
2. Plug the headset into the computer by USB and open SideQuest, then click USB detected.
3. In SideQuest, choose the option to install an APK file from the computer and select the downloaded file.
4. On the headset, open Unknown Sources and launch Dramatic Shape.
5. Import the game files for each pak shown: R (Red), B (Blue), Y (Yellow) and Stadium.
6. Launch an imported game from the list; the world loads first before the game is ready.
