### Key steps

1. Open reactbits.dev and pick a category: Text Animations, Animations, Components or Backgrounds.
2. Open a component page and adjust its props in the live preview.
3. Open the Code tab and choose a variant: JS or TS, and CSS or Tailwind.
4. Either copy the code into your project and install the dependencies listed on the page, or use the CLI: npx shadcn@latest add @react-bits/SplitText-TS-TW. Swap SplitText for your component. The suffix sets the variant (JS or TS, then CSS or TW).
5. Import the component into your React app and render it.
