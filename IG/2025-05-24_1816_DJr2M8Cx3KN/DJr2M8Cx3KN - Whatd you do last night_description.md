# Startup update: scraping Reddit for landing page copy

The creator describes his previous night's work on his startup: a ChatGPT-written scraper that pulled r/ADHD posts and comments, cleaned into NotebookLM for customer research, and a landing page rewritten in users' own words. The reel shows a terminal running the scraper and the creator talking to the camera.

Written by claude-haiku-5-5.

## What it teaches

1. Have ChatGPT write a scraper that collects posts matching keywords from a subreddit (r/ADHD) and all of their comments.
2. Run a script to clean the scraped data so it is readable.
3. Load the cleaned data into NotebookLM and ask it about the key emotional drivers of your ideal customer.
4. Ask NotebookLM to point to the most relevant posts and comments, then read those yourself.
5. Rewrite the landing page and ad copy using the same words users use to describe themselves.
6. Make sure the landing page works well on mobile, since most users will view it there.
7. Drive traffic to the landing page and A/B test the copy until one performs well.
