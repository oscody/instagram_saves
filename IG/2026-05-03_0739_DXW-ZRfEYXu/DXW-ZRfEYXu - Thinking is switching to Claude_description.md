# Switching from ChatGPT to Claude: three steps

A short video urging ChatGPT users to switch to Claude, with three setup steps: turn on memory, import memories from ChatGPT, and use Anthropic's free AI courses. On-screen text shows a Claude chat asking it to summarize course lessons for the user's workflow.

Written by claude-haiku-5-5.

## What it teaches

1. Open Settings, go to Capabilities, and turn on the two memory settings so Claude can remember context across your chats.
2. In Settings > Capabilities, find the option to import memories from other AI providers and copy the prompt it gives you.
3. Paste that prompt into ChatGPT and copy ChatGPT's response.
4. Paste ChatGPT's response back into the same box in Claude so Claude learns about you.
5. Find Anthropic's free AI courses (13 certifications, per the video) and paste their URLs into Claude.
6. Ask Claude to summarize the most valuable parts of the courses for your workflow, and to help install the skills you need.

### Key steps

1. In Claude: profile picture > Settings > Memory (or Settings > Capabilities on older UI). Turn on memory / 'Generate memories from chats'.
2. Next to 'Import memory from other AI providers', click Start Import and copy the prompt.
3. In ChatGPT, make sure memory is on (Personalization). Paste the prompt in a new chat and copy the full output.
4. Paste the output into Claude's import field and click Add to memory. It can take up to 24 hours.
5. Review the imported memories under Settings > Memory and trim outdated entries.
6. Sign up free at anthropic.skilljar.com, then paste course URLs into Claude and ask it to summarize the parts useful for your workflow.
