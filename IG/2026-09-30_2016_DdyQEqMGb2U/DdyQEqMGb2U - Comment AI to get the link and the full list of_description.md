# FreeMoCap: turn webcams into a mocap rig

The carousel presents FreeMoCap, an open-source tool that uses a few USB webcams to capture 3D skeletal motion without markers, infrared cameras or a studio. Its slides show a 3D skeleton and hand-position graphs from recorded footage.

Written by claude-haiku-5-5.

## What it teaches

1. Install the tool with one command: pip install freemocap
2. Point a few USB webcams at a subject
3. Record the subject
4. The tool extracts 3D skeletal motion, joint positions, angles and movement data from the recording
