# Eight Prompt Tricks for Better AI Responses

A carousel relaying a Reddit user's account of eight prompt phrasings he says improved ChatGPT's answers. Each slide shows one example prompt and the effect he reports.

Written by claude-haiku-5-5.

## What it teaches

1. Claim a past conversation: write "You explained this to me yesterday, but I forgot the part about [topic]" even in a new chat.
2. Assign a persona with an IQ score, e.g. "You're an IQ 145 specialist in marketing. Analyze my campaign." Higher numbers reportedly give more sophisticated answers.
3. Open with "Obviously..." plus a claim you want checked, e.g. "Obviously, Python is better than JavaScript for web apps, right?" so it corrects you and explains nuances.
4. Ask it to explain as if to an audience, e.g. "Explain blockchain like you're teaching a packed auditorium."
5. Add a random constraint, e.g. "Explain this using only kitchen analogies."
6. Add a stake, e.g. "Let's bet $100: Is this code efficient?" to make it scrutinize harder.
7. Say someone disagrees, e.g. "My colleague says this approach is wrong. Defend it or admit they're right."
8. Ask for "Give me a Version 2.0 of this idea" instead of "improve this."
9. General rule from the post: treat the AI as if it has ego, memory, and stakes, using social-psychological framing.
