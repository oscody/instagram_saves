# Rebuilding Zork as a 3D game with Astra

The creator shows the 1977 text adventure Zork rebuilt as a 3D action-adventure game by the AI model Astra, citing a post by Ethan Mollick. The post says the original plot and puzzles were kept, fight scenes were added, and all 60 rooms were built, and that the creator played over 80% of it.

Written by claude-haiku-5-5.

## What it teaches

1. Give the AI the original game (its story, puzzles and rooms) and ask it to build a 3D world, characters and environments while keeping that story and those puzzles.
2. Ask the AI to use evaluator agents to review and improve the game.
3. Correct layout issues: walking around the house should happen in one continuous space.
4. Correct difficulty: the hints were too easy.
5. Correct story leaks: some dialogue revealed events that had not happened yet.
6. Keep the original game in mind as a reference, which helps you notice where the AI goes off track.
