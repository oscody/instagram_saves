# Browser games for learning Python, neural nets, AI safety

The reel shows several browser-based game-style sites for learning AI topics: a Python course with dungeon, farm and mine games, an interactive neural network playground, and a prompt-based AI safety game where you try to get a guard bot to reveal a password.

Written by claude-haiku-5-5.

## What it teaches

1. Learn Python by running code yourself in the browser, with no installation, by repeating challenge loops.
2. Progress through each game's levels in order, from basics to advanced topics.
3. Experiment with a neural network's settings (learning rate, activation, regularization, layers) and watch how the output changes.
4. Try different messages to a chatbot guard to see how it can be tricked into revealing a secret.
