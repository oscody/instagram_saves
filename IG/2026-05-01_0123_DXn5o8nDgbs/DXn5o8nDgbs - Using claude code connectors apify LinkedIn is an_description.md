# Claude connectors with Apify for LinkedIn outreach

The reel shows how to add the Apify connector in Claude and use its LinkedIn scrapers to find job openings, scrape hiring managers, and draft personalized cold emails for each one. The on-screen steps are the Claude connector menu, the Apify Store search for LinkedIn actors, and a web-scraping overview page.

Written by claude-haiku-5-5.

## What it teaches

1. In Claude, open the + menu, go to Connectors, and choose Add connector.
2. Search for Apify and connect it so Claude can use its web scraping tools, including a LinkedIn scraper.
3. In the Apify Store, search 'linkedin' to find LinkedIn actors such as jobs scrapers, profile scrapers, and post search scrapers.
4. Tell Claude your dream job; it uses the LinkedIn actor to find matching openings.
5. Have Claude scrape the hiring managers for those openings.
6. Have Claude write a personalized cold email for each hiring manager, then review and send them.
