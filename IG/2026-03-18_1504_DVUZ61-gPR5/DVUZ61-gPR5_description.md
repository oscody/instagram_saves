# Migrating chat history from chat to beauty to cloud

A woman in a white shirt, sitting with a closed laptop, explains how to move your years of conversation history and data from "chat to beauty" to "cloud" so you don't start from scratch. She says the export takes roughly a day, though the on-screen text says 24 to 48 hours.

Written by claude-haiku-5-5.

## What it teaches

1. In chat to beauty, open Settings, tap Data, then choose Export.
2. Wait for the export email, which can take 24 to 48 hours (the speaker's took about a day).
3. Download the zip file from the email.
4. In cloud, create a project and upload the entire zip file into it so cloud gets your historical context.
5. For more precision, you can instead download individual chats as markdown files and add those to a cloud project, but this is more time consuming and manual.
