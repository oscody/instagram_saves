# Arcane-style animation workflow using Claude

A reel walking through an Arcane-style animation process in Claude, from gathering references to generating a dancing character video. The caption and closing line point viewers to a comment for the full workflow.

Written by claude-haiku-5-5.

## What it teaches

1. Collect good Arcane-style references from Pinterest or Google.
2. Feed the references into Claude to analyze them and record the aesthetic.
3. Connect at least two Claude tools through MCP so images and video can be generated inside Claude.
4. Describe the character and the location to Claude.
5. Have Claude generate a character sheet and a location sheet.
6. Ask Claude to generate a video of the character dancing.
