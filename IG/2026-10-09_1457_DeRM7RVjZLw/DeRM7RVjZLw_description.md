# Compass: a free Obsidian life-journaling vault

The post introduces Compass, a free Obsidian vault that combines nightly journaling, habit tracking, planning, retreats and tasks in one folder. On screen is its GitHub README, including its quick-start setup.

Written by claude-haiku-5-5.

## What it teaches

1. Download the zip from Releases or clone the repository; the repository root is the vault.
2. In Obsidian, choose 'Open folder as vault'.
3. If Obsidian asks about Restricted mode, click 'Turn off'.
4. Run the command 'Reload app without saving' so the ten community plugins and Life OS load; Life OS opens automatically after reload.
5. Open '00 Dashboards/Setup.md', which checks itself and lists what is left to do.
6. Each night, press Ctrl/Cmd+Shift+D to open today's note and Ctrl/Cmd+Shift+Q to answer the questions.
7. Answer 1 to 10 and write one line under '## Journal', then stop; everything else waits 30 days.
8. Delete the notes tagged 'example' once the Setup checklist reminds you to; they are seed data so the dashboards render on first open.
