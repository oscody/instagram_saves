# Four Android dial codes for phone maintenance

A short Reel that presents four dial codes for Android phones, with screen captures of the dialer, a test menu, and a "Main version" info screen. The codes for the second to fourth items are not shown on screen or named in the transcript.

Written by claude-haiku-5-5.

## What it teaches

1. Code 1: dial the code shown on the dialer (ending in #9900#) to delete junk files from the phone, which the post says makes it slightly faster.
2. Code 2: dial the second code (not shown on screen) to activate General Test Mode, where you can test almost every function of the phone. The test menu on screen lists Red, Green, Blue, Receiver, Vibration, Mega Cam, Sensor, Touch, Speaker, Sub Key, Front Cam, Black, Hall IC, MLC, S-Pen and Loopback.
3. Code 3: dial the third code (not shown on screen) to refresh the Wi-Fi version, which the post says improves Wi-Fi performance.
4. Code 4: dial the fourth code (not shown on screen) to see the phone's original date of use, which the post says is useful when buying a second-hand phone. The resulting screen is titled Main version and lists fields such as BL, AP, CP, CSC, RF Cal and HW Rev.

It lists *#9900# (SysDump), *#0*# (hardware test menu) and *#1234# (AP/CP/CSC version info), which match the on-screen menus.

### Key steps

1. Open the stock Samsung Phone app. Google Dialer and other third-party dialers don't run these codes.
2. Dial *#0*# to open the hardware test menu (display colors, touch, sensors, speaker, vibration, cameras).
3. Dial *#1234# to see the AP, CP and CSC version details. The post presents this screen as the phone's original date of use, but it shows firmware versions, so treat that claim cautiously.
4. Dial *#9900# for SysDump diagnostics. It's a diagnostic tool, so don't expect a speed boost. Skip options you don't understand.
5. Avoid factory-reset codes. Samsung has disabled most of them on One UI 7 and later.
