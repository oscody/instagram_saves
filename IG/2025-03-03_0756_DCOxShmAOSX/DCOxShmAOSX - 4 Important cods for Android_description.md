# Four Android dial codes for phone maintenance

A short Reel that presents four dial codes for Android phones, with screen captures of the dialer, a test menu, and a "Main version" info screen. The codes for the second to fourth items are not shown on screen or named in the transcript.

## What it teaches

1. Code 1: dial the code shown on the dialer (ending in #9900#) to delete junk files from the phone, which the post says makes it slightly faster.
2. Code 2: dial the second code (not shown on screen) to activate General Test Mode, where you can test almost every function of the phone. 3. Code 3: dial the third code (not shown on screen) to refresh the Wi-Fi version, which the post says improves Wi-Fi performance.
4. Code 4: dial the fourth code (not shown on screen) to see the phone's original date of use, which the post says is useful when buying a second-hand phone. The resulting screen is titled Main version and lists fields such as BL, AP, CP, CSC, RF Cal and HW Rev.
