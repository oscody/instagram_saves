# Stop hitting Claude limits: context habits

A short carousel-style reel explaining why Claude chats run out of usage: each message resends the whole conversation, so long pasted PDFs get reread every time. It walks through a three-part set of steps (why, the fix, routing) with a Claude docs diagram of the context window.

Written by claude-haiku-5-5.

## What it teaches

1. Start a fresh chat for each task instead of continuing one long conversation, because every message resends the whole chat history.
2. Have the AI condense a large document into a one-page summary once, then put that summary in a Claude project and leave the original PDF out.
3. When you need an exact number from the PDF, open the PDF in its own separate chat.
4. Write down what the AI needs to know for a task and what to leave out (context engineering).
5. Send each job to the cheapest model that can handle it, rather than using a large model for simple yes-or-no tasks.
