### Key steps

1. Install Node.js 18+ and use Chrome or Edge.
2. Clone the repo and open the project folder.
3. Run `npm install`. It copies the MediaPipe files and downloads the hand model into public/.
4. Run `npm run dev`.
5. Open the URL Vite prints (usually http://localhost:5173) and click Start camera.
6. Gestures: open your hand to explode the model, make a fist to reassemble, point to select a part, pinch to pull a part out, use two hands to zoom, and hold a peace sign to switch models.
7. Without a camera: drag to rotate, scroll to zoom, press Space to explode, and press 1–4 to switch models.
