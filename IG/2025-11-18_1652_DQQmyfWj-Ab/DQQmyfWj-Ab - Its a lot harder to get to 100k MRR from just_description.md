# Tool stack for building a 100k MRR app

A creator walks through the tools he says founders use to build apps toward $100k monthly recurring revenue. He notes that growth beyond vibecoding also depends on Google, Meta ads, and UGC.

Written by claude-haiku-5-5.

## What it teaches

1. Use Lovable or Replit to build out the starting template.
2. Use Next.js with TypeScript and Tailwind CSS for the framework if building a website, or React Native if building an app.
3. Use Claude Code for coding.
4. Host websites on Vercel.
5. Use Supabase for authentication and database management.
6. Use Resend for sending email.
7. Use PostHog for analytics.
8. Use Stripe for payments.
9. Use Stripe Atlas for company incorporation.
10. If building an AI app, use the OpenAI API.
11. Use GitHub for code collaboration.
12. Buy and manage your domain with Porkbun if building a website.
13. Use Google Workspace to get a company domain email address for Gmail.

## Caption

It’s a lot harder to get to 100k MRR from just vibecoding but this would give you the stack you need go build out any app! The rest comes from google, meta ads, and UGC
