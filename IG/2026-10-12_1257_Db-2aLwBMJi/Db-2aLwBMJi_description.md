# Giving and receiving notes on animation work

A VFX artist recounts a costly note from a Call of Duty project, where a vague request for "light snow" led to revisions. The reel is a talking-head video shown across a bright office window scene and a purple gaming room.

Written by claude-haiku-5-5.

## What it teaches

1. When giving notes on animation, explain everything: the shape, motion blur, and how the effect interacts with the ground and CG characters.
2. Don't assume the other person shares your context, since a skilled artist can picture many different versions of the same note.
3. If a note is a loose idea, say so explicitly so the artist knows they can run with it.
4. When receiving notes, restate what you understood back to the giver as a question ("Is this what you mean?") instead of replying with a simple "okay" or "yes".
