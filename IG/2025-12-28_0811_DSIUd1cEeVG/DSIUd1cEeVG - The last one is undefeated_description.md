### Key steps

1. AI-For-Beginners: git clone https://github.com/microsoft/AI-For-Beginners.git, then follow lessons/0-course-setup/setup.md (VS Code or Codespaces).
2. Made-With-ML: clone the repo, create a .env with GITHUB_USERNAME, make a Python 3.10 venv, pip install -r requirements.txt, and run pre-commit install.
3. Made-With-ML: open notebooks/madewithml.ipynb, and read the lessons at madewithml.com.
4. awesome-llm-apps: clone it, cd into a starter_ai_agents/ project, run pip install -r requirements.txt, then run the app (e.g. streamlit run travel_agent.py) with an API key.
