# 12-month robotics learning plan, month by month

A creator outlines a 12-month robotics learning roadmap, split into phases with the projects and skills planned for each block. The on-screen slides list the projects for Level 2 (months 3-4) and Level 5 (months 10-12).

Written by claude-haiku-5-5.

## What it teaches

1. Months 1-2: rebuild basics in code and circuits, starting with an LED blink, then simple motor and sensor projects.
2. Months 3-4: move to smarter robots with a Bluetooth-controlled robot, a self-balancing robot (IMU + PID), and a mini robotic arm with 3-4 servos (the transcript also mentions a mini robotic car).
3. Months 5-6: build a camera robot that follows you, a real-time object-tracking camera, and a robotic gripper; learn 3D modeling and 3D printing, and basic computer vision.
4. Months 7-9: build an automated rover and a voice-controlled robot assistant; learn ROS2; study pathfinding and mapping while building a mini Roomba-style robot.
5. Months 10-12: integrate AI into the hardware so robots make their own decisions; build a smart companion robot that listens, sees and moves, an AI-powered vision-guided pick-and-place robot arm, and a final flagship project (a personal robot assistant).
