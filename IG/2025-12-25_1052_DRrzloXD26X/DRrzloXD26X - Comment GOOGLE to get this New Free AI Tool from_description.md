# Google CodeWiki: Understanding GitHub Codebases

The post introduces Google's free CodeWiki tool, which turns a GitHub repo into an interactive wiki with diagrams, code explanations, videos and a chatbot. It walks through the example of the gemini-cli repo.

Written by claude-haiku-5-5.

## What it teaches

1. Open Codewiki.
2. Paste the GitHub repo URL into the tool.
3. Browse the generated wiki: architecture diagrams, code breakdowns and explanation videos.
4. Use the built-in chat, 'Ask about this repository', when you get stuck on a function or module.
5. Note that the tool currently works only with open-source repos, and the wiki updates when the code changes.
