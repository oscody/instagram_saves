# Old Cellphones as Personal AI Servers

A creator shows a purple 3D-printed case with a fan that holds an old Pixel phone running a small AI model as a personal server. He shows a chat screen where the model picks a random one-sentence quote, and says several old phones could split a large job between them.

Written by claude-haiku-5-5.

## What it teaches

1. Run a small, current-generation AI model on an old Android phone, such as a Pixel 4A.
2. Split a large batch of tasks evenly across several old phones.
3. Have the phones take turns working through the tasks over a long period.
4. Give the models strict guidelines and tests for multi-step processes.
