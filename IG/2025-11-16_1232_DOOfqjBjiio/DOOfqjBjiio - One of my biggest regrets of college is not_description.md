# Regret not building in college; start projects now

A creator says his biggest college regret is not building more things while focused on classes, and that he would prioritize building over grades if he redid college. He shows two projects he says got him into Google: a Chrome extension called Audible Recall that summarizes the past X pages of a PDF, and a two-player strategy board game (Ataxx) with AI computer players.

Written by claude-haiku-5-5.

## What it teaches

1. Prioritize building projects over doing well in classes
2. Use AI tools to build almost anything
3. Expect interviews to shift toward builder-focused tests of foundational skills instead of LeetCode-style problems
4. Start building projects now

## Caption

One of my biggest regrets of college is not building more stuff (because I was so busy studying for classes) 

1000% if I were to redo college, I would prioritize building stuff OVER doing well in my classes. 

ESPECIALLY with AI now, there is really no reason you can’t build ANYTHING.

I anticipate a lot of companies will start shifting their interview processes to be more builder focused and revolved around foundational skills rather than how well you can leetcode, so the best time to start building projects is now!
