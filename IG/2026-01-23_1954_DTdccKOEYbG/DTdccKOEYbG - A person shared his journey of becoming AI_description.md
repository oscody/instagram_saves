# Phased roadmap to becoming an AI engineer

A reel relaying a Reddit user's phase-by-phase path into AI engineering, with the courses, resources and projects he used at each stage. It also says he open-sourced his projects and shared them on LinkedIn to get recruiter outreach.

Written by claude-haiku-5-5.

## What it teaches

1. Phase 1 (1-2 months): if your Python is rusty, spend a week on decorators, async and virtual environments; skip this if Python is already solid.
2. Phase 1: learn the math and ML foundations with Khan Academy (linear algebra, probability, stats) and 3Blue1Brown's Essence of Linear Algebra series.
3. Phase 1: take Andrew Ng's Machine Learning course on Coursera for the intuition behind algorithms.
4. Phase 2 (2-3 months): build practical ML skills with fast.ai's Practical Deep Learning course, creating your own models from day one.
5. Phase 2: take Andrew Ng's Deep Learning Specialization, which covers TensorFlow and PyTorch.
6. Phase 3 (3-4 months): learn modern AI and LLMs using the LangChain documentation, the Hugging Face course, Pinecone documentation and the OpenAI API docs.
7. Phase 3 project: build a RAG chatbot (PDF upload, embeddings, retrieval, GPT-3.5 answer with memory).
8. Phase 3 project: fine-tune Llama 2 for code review.
9. Phase 3 project: build a multi-modal app for image captioning and Q&A using CLIP and BLIP models.
10. Deployment basics (mentioned in the reel): build APIs with FastAPI, containerize models, and deploy on AWS SageMaker or GCP Vertex AI.
11. Job search: spend the final months applying and interviewing, and open-source your projects and share them on LinkedIn to attract recruiter outreach.

2. Phase 2 (2-3 months): do fast.ai Practical Deep Learning, then Ng's Deep Learning Specialization.
3. Phase 3 (3-4 months): study the LangChain, Hugging Face, Pinecone and OpenAI API docs.
4. Build three projects: a RAG chatbot with PDF upload and memory, a Llama 2 fine-tune for code review, and an image captioning and Q&A app using CLIP and BLIP.
5. Learn deployment: FastAPI, containers, and AWS SageMaker or GCP Vertex AI.
