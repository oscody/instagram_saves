### Key steps

1. Start with microsoft/generative-ai-for-beginners: do Lesson 00 (Course Setup) and fork the repo.
2. Pick a model provider (Azure OpenAI, Microsoft Foundry Models, OpenAI API, or Foundry Local for offline use). The README says GitHub Models retires at the end of July 2026.
3. Use a sparse checkout that skips the translations folders to keep the clone small.
4. Browse awesome-llm-apps for runnable agent and RAG examples, and awesome-mcp-servers for MCP setups.
5. Use 100-Days-Of-ML-Code for classic ML practice.
