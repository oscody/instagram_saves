## What it teaches

1. Stop relying only on watching tutorials, because they can leave you unable to build on a blank project.
2. Learn by building real projects, such as games, web apps, bots, databases, compilers or operating systems.
3. Pick one programming language you are learning and choose a project in it.
4. Pick one project and start building it.
5. Expect to learn more from debugging that project than from watching more hours of tutorials.
