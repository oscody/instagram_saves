# Context engineering for AI coding agents

A creator says he built his quant trading app by feeding Claude Code hundreds of hours of trading research and turning it into specialized agents and skills. He presents this as context engineering rather than prompt engineering.

Written by claude-haiku-5-5.

## What it teaches

1. Treat every task as if the agent knows nothing, and leave no room for assumptions.
2. Ask the agent to research the topic, such as finding articles and frameworks from well-known traders or hedge fund owners and their best practices.
3. Have the agent write the research into one or more documents.
4. Turn those documents into skills or sub-agents so the agent has domain context.
5. When you find a useful YouTube video, get its transcript (he uses Google Gemini Studio) and give it to the coding agent.
6. Ask the agent what can be extracted from the transcript and how it can be applied.

### Key steps

1. Tell the agent to assume it knows nothing about the domain, and spell out the context.
2. Ask it to research the topic: articles and frameworks from respected practitioners, and their best practices.
3. Have it write the findings into one or more markdown documents.
4. Turn those documents into Claude Code skills or sub-agents so the domain context loads when needed.
5. Get transcripts of useful YouTube videos (he uses Google Gemini Studio) and give them to the agent.
6. Ask the agent what can be extracted from each transcript and how to apply it to the project.
