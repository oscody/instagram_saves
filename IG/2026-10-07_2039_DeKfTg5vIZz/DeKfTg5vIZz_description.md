# AI second brain as text files

The post explains an "AI second brain" as a set of text files that give an AI agent context about your voice, audience, and business. It shows a folder structure for an ai-brain directory and says a fuller setup is offered to viewers who comment.

Written by claude-haiku-5-5.

## What it teaches

1. Keep the AI brain as a set of plain text files.
2. Create a voice file that captures how you sound (My-Voice.md).
3. Create an audience file describing who you speak to (My-Audience.md).
4. Create a business file describing your business (My-Business.md).
5. Add a management file that decides which context to pull and when (CLAUDE.md).
6. Dump new material into the folders (AI-Chats, Emails, Inspiration, Other, Transcripts, Voice-Recordings) so the brain keeps getting updated.
7. Move the same setup between AI apps if you want to switch tools.
