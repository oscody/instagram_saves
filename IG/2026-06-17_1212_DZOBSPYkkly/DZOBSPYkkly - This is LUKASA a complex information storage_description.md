# Lukasa: Luba Kingdom's beaded memory board

A narrator presents the Lukasa, a hand-held wooden board covered in beads, shells and metal pins, made by the Luba Kingdom in today's Democratic Republic of Congo. He compares its structure and logic to how modern computers store binary data.

## Research

* Verdict: Partly valid. The lukasa is a real Luba memory board used to store history, but the "before the 16th century" date is not firmly established. The computer-binary comparison is a loose analogy.
