### Key steps

1. Requires Node.js 22.20 or later.
2. Browse skills.sh to pick a skill and note its owner/repo.
3. Run `npx skills add <owner/repo>` in your project. It asks which skills and agents to install to.
4. To install one skill for Claude Code: `npx skills add <owner/repo> --skill <name> -a claude-code`.
5. Add `-g` to install the skill for all projects.
6. Search with `npx skills find <query>` and list installed skills with `npx skills list`.
7. Update with `npx skills update` or remove with `npx skills remove`.
8. Try a skill without installing: `npx skills use <source>@<skill> --agent claude-code`.
