# Why AI agents shouldn't deploy on Vercel

A man speaks outdoors urging builders of AI agents or API-based products not to deploy on Vercel. He argues that pay-per-request serverless charges can become very large as users grow, and recommends a VPS instead.

Written by claude-haiku-5-5.

## What it teaches

1. For an AI agent or API-based product, don't deploy on Vercel, because serverless functions charge for every API request.
2. Don't use a hosted backend service for the backend either; run everything on a VPS.
3. Expect the VPS to be harder: learn to manage it, lock it down, and upgrade it.
4. Learn security basics, such as using strong SSH keys.
5. Treat VPS management as a skill that lets you scale the app and stand out.
