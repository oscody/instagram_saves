### Key steps

1. Update Claude Code with `claude update`. Write-ups say mods are on by default from about version 2.1.287.
2. Comment "HACKED" on the reel to get Nate's mod text, or ask Claude to write the behavior you want.
3. Paste a mod's text into Claude Code and say "set up this mod."
4. Or install a packaged mod with `claude plugin marketplace add <repo>`, then `claude plugin install <name>@<marketplace> --scope user`.
5. Start a fresh session, because mods don't load into a running one. Check with `/plugin`.
6. Read the mod code before installing. Mods are not sandboxed and run with your file, network and key access.
7. Collision Guard only prompts you before an edit. It does not block, so unattended sessions are not protected.
