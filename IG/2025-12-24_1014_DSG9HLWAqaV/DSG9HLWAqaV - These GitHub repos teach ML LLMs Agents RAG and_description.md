### Resources

* [microsoft/ML-For-Beginners (github.com)](https://github.com/microsoft/ML-For-Beginners): repo, found by search, verified, high confidence. Opened it: a 12-week, 26-lesson classic ML curriculum from Microsoft.
* [mrdbourke/pytorch-deep-learning (github.com)](https://github.com/mrdbourke/pytorch-deep-learning): repo, found by search, verified, high confidence. Opened it: materials for the Learn PyTorch for Deep Learning course.
* [microsoft/ai-agents-for-beginners (github.com)](https://github.com/microsoft/ai-agents-for-beginners): repo, found by search, verified, high confidence. Opened it: an 18-lesson course on building AI agents.
* [dair-ai/Prompt-Engineering-Guide (github.com)](https://github.com/dair-ai/Prompt-Engineering-Guide): repo, found by search, verified, high confidence. Opened it: guides and papers on prompt engineering, RAG and agents.
* [mlabonne/llm-course (github.com)](https://github.com/mlabonne/llm-course): repo, found by search, verified, high confidence. Opened it: an LLM course with roadmaps and Colab notebooks.

### Key steps

1. Start with microsoft/ML-For-Beginners for ML basics.
2. Move to mrdbourke/pytorch-deep-learning for PyTorch and deep learning.
3. Use mlabonne/llm-course for LLM theory, fine-tuning and deployment.
4. Use microsoft/ai-agents-for-beginners to build agents.
5. Use dair-ai/Prompt-Engineering-Guide for prompting, RAG and agent techniques.
